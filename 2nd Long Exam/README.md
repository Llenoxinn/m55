## Source layout

```
src/
├── build.ps1                 # builds every document and copies the PDFs here
├── shared/
│   ├── preamble.tex          # common look (matches Lecture Notes 01)
│   └── m55plot.py            # common matplotlib style for figures
├── lecture-notes-02/
│   ├── lecture-notes-02.tex  # main file: \input's the sections in order
│   ├── sections/             # one .tex file per chapter
│   └── figures/              # make_figures.py + the generated PDFs
├── lecture-notes-03/         # same layout
└── mock-exams/               # same layout
```

## Building

Needs a TeX distribution with `latexmk` (MiKTeX or TeX Live). From this folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\src\build.ps1             # everything
powershell -ExecutionPolicy Bypass -File .\src\build.ps1 -Only lecture-notes-02
powershell -ExecutionPolicy Bypass -File .\src\build.ps1 -Figures    # also redraw figures
```

or by hand, from a document's folder: `latexmk -pdf -outdir=build lecture-notes-02.tex`.

**Overleaf:** upload the whole `src/` folder, open e.g. `lecture-notes-02/lecture-notes-02.tex`
and set it as the main document (the files use relative paths such as `../shared/preamble.tex`).

Figures are generated by `figures/make_figures.py` (Python 3 + matplotlib + numpy) and the
resulting PDFs are committed, so a LaTeX build does not need Python.
