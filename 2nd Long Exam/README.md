What each reviewer contains:

- **No. 6 – Directional Derivatives:** preliminaries (partials, differentiability, chain rule),
  limit definition and formula for `D_u f` (with proof), the gradient and the maximum-rate
  theorem, the trio activity solved, level curves/tangent planes/steepest ascent,
  26 practice problems with full solutions, formula summary, common mistakes.
- **No. 7 – Vector Calculus:** vector fields (Example 7.1, Exercises 1–3 solved with figures),
  gradient fields, the component test and why it works, the three-step potential method
  (Example 7.6, Exercise 4), the domain caveat (vortex field), 21 practice problems, summary.
- **Cheat Sheet:** formula tables and standard methods for Topics 5, 6 and 7; checklists and
  labelled galleries for matching vector functions to space curves and vector fields / gradients
  to their plots (plus a picture → formula look-up table); 14 graph-identification practice items
  with answers.
- **Mock Exams:** Form A (12 problems) and Form B (14 problems), 100 pts each, full
  solutions with point breakdowns, and a one-page answer key mapping each problem to the notes.

## Building

Needs a TeX distribution with `latexmk` (MiKTeX or TeX Live). From this folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\src\build.ps1             # everything
powershell -ExecutionPolicy Bypass -File .\src\build.ps1 -Only lecture-notes-02
powershell -ExecutionPolicy Bypass -File .\src\build.ps1 -Figures    # also redraw figures
```

or by hand, from a document's folder: `latexmk -pdf -outdir=build lecture-notes-02.tex`.

**Overleaf:** upload the whole `src/` folder, open e.g. `lecture-notes-02/lecture-notes-02.tex`
and set it as the main document (the files use relative paths such as `../shared/preamble.tex`).

Figures are generated by `figures/make_figures.py` (Python 3 + matplotlib + numpy) and the
resulting PDFs are committed, so a LaTeX build does not need Python.
